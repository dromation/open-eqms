# Architecture

This directory contains the authoritative architecture and governance records for Open-EQMS.

`Open-EQMS_Architecture_Baseline_v1.0.md` is the normative, approved, authoritative reference for implementation.

`Open-EQMS_Architecture_Freeze_Review.md` is historical, explanatory, and non-normative.

Architecture changes require an approved ADR before implementation. Implementation SPECs belong under `architecture/spec/` and must stay consistent with the Baseline and approved ADRs.
