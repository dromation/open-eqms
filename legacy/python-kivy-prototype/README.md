# Python/Kivy Prototype

This directory contains the historical Open-EQMS Python/Kivy/Lua prototype.

It predates Architecture Baseline v1.0 and is preserved for history and reference. It is not the active implementation.

The prototype must not be used as the architectural foundation for the new Runtime. The current Open-EQMS implementation target is the native, deterministic Business Runtime Platform defined by Architecture Baseline v1.0.

No compatibility between this prototype and the new Runtime is currently guaranteed.
