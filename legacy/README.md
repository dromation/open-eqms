# Legacy

This directory preserves historical Open-EQMS implementation material.

The contents here predate Architecture Baseline v1.0. They are kept for history and reference, not as the active implementation.

The historical Python/Kivy/Lua prototype is preserved under `legacy/python-kivy-prototype/`. It must not be used as the architectural foundation for the new Runtime.

No compatibility between the prototype and the new Runtime is currently guaranteed.

Moving historical material into `legacy/` does not change its original license. The repository remains under the GPL-2.0 license recorded in the root `LICENSE` file.
