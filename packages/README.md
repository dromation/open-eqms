# Packages

This directory is reserved for Open-EQMS Content Packages.

Content Packages define business applications through declarative package data: objects, relations, events, rules, processes, forms, views, reports, statistics, KPIs, translations, document templates, and capability manifests.

Business methods belong in packages, not in the Runtime.

Internal structure under `packages/` will be created only through approved SPECs and ADRs. Do not add speculative package formats, SDKs, builders, sample packages, or implementation dependencies during Phase 0.
