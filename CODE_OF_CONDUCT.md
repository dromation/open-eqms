# Code of Conduct

Open-EQMS expects professional, respectful collaboration.

## Expected Behavior

Participants should:

- Be respectful and direct.
- Focus criticism on ideas, code, documents, and behavior.
- Assume technical claims need evidence.
- Give maintainers enough context to reproduce and review issues.
- Respect project governance and review boundaries.

## Unacceptable Behavior

The following are not acceptable:

- Harassment, threats, intimidation, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without consent.
- Deliberately derailing technical review.
- Abusive behavior toward maintainers, contributors, or users.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, restrict participation, or take other reasonable action when behavior harms the project or its contributors.

Reports should be sent privately to the project maintainers whenever possible. Do not include sensitive personal information in public issues.

## Scope

This code of conduct applies to project spaces including GitHub issues, pull requests, discussions, documentation, and other official Open-EQMS collaboration channels.
